# Mission: Ship a Kid-Friendly App Store App

## Why

You're a frontend web developer who wants to release a simple, kid-friendly app to the App Store. You want kids' data to stay on the device for privacy and compliance, while still letting families export daily, weekly, or monthly progress sheets — ideally to a parent's phone via email.

## Success looks like

- Choose a realistic tech stack (likely React Native / Expo) given your web background
- Understand how on-device storage, report generation, and sharing work without a backend
- Design a kid-safe architecture that satisfies App Store Kids Category rules
- Ship a working MVP to TestFlight, then the App Store

## Constraints

- Frontend web developer background — prefer familiar tools (JavaScript/TypeScript, React)
- Simple and kid-friendly UX
- Data should live on the device by default (no cloud account required)
- Parents/caregivers may want periodic sheets sent to their phone

## Out of scope

- Building the full app in this teaching workspace (lessons teach concepts; code lives elsewhere)
- Backend servers, user accounts, or cloud sync (unless we later decide they're needed)
- Android Play Store specifics until iOS path is clear
